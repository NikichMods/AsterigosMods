# Состояние проекта

- [CombatHUD](../mods/CombatHUD/docs/STATUS.md) — Приглушение нижних панелей интерфейса вне боя.
- [SoulsEnemyHUD](../mods/SoulsEnemyHUD/docs/STATUS.md) — Компактные полоски противников, маркер захвата и суммирующийся урон.
- [ProfileRender](../mods/ProfileRender/docs/STATUS.md) — Разрешение Хильды в меню профиля: два буфера1600×1800.
- [SubtitleSoftEdges](../mods/SubtitleSoftEdges/docs/STATUS.md) — Мягкие края фоновой подложки субтитров.
- [AnimationRate](../mods/AnimationRate/docs/STATUS.md) — Настройка a.URO.Enable=0 для анимаций дальних врагов.
