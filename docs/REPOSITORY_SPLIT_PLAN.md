## Safe migration sequence

1. **Local read-only preflight (user-mediated Windows Codex):** verify active checkout/worktrees, branch/HEAD, dirty/untracked/ignored material, other writers, installed mods and process state, game files, external tools, candidate archives, rollback and hashes. Inventory .local, original pre-import archive and proprietary inputs by names/hashes without exposing content. Check actual `git/refs` and Release assets again.
2. **Remote preparation:** create six distinct repos under the verified `NikichMods` identity (not empty placeholders called completed migrations). Set visibility to public only for source known to be redistributable, keeping game/host-derived files out. Apply `game-asterigos` and `nikichmods-mod` topics after checking existing topic conventions. No parent repository/submodules.
3. **Per-mod import:** operate in isolated new directories/worktrees, never rename the busy source checkout. Use a path-aware history extraction such as `git subtree split --prefix=<mod>` when it preserves useful module history, or a documented byte-verified import when it does not. Original SHA, path and tag links remain in the original repo; never claim rewritten child commit IDs are the originals. Copy only tracked eligible mod source/docs/tests/tools; install root `LICENSE`, adapted `LICENSING.md`, scoped `.gitignore/.gitattributes`, independent test runner and exact Research pointer. Keep original production Lua/CSS/recipe/ini bytes identical, including line endings; validate both Git blobs and SHA-256 of accepted files before/after. Preserve prior candidate/test evidence and deliberate deferred states.
4. **Cross-mod build boundary:** `SoulsEnemyHUD` standalone runtime Lua and authored UI addon belong to its repository; its current installed `z330` is composed from proprietary `Hud.html` plus the *unchanged* SubtitleSoftEdges patch. Record this integration input by provenance/hash and an external ignored local path. It is a build-time composition dependency, not permission to copy game HTML to Git or silently mutate SubtitleSoftEdges. Do not claim standalone pak reproducibility until locally proved. Other game resources/tools/fonts and the `ProfileRender` accepted payload remain external/ignored.
5. **Local data:** COPY, do not relocate/delete, selected `.local/candidates`, `.local/accepted-payload`, research inputs and rollback into owner-specific ignored paths after identifying each item and verifying hashes. Preserve existing full historical archive. Do not change running installation, `mods.txt`, saves, package overlays, loaders or graphical settings during organizational migration. Do not remove current rolled-back files.
6. **Independent validation:** per-repo Git clean state, provenance, Research links, version/tag claims, README/install steps, isolated tests and build/packaging where possible. Original accepted assets must retain identical hashes; new tests do not replace game acceptance. Check what cannot be built without proprietary inputs and state it honestly. Push and fetch exact GitHub revisions; verify Releases remain downloadable at old URLs and refs unchanged.
7. **Cutover only after all six pass:** update new owning `AGENTS.md`/status docs and ChatGPT Project adapters (`CombatHUD` previously root `docs/CHATGPT_PROJECT_INSTRUCTIONS.md`; `ImmersiveInteractionPrompts` module adapter). Update Research links/index and old README/AGENTS to a small historical navigation archive. Do not delete, archive-lock, rename or rewrite `AsterigosMods`; retain tags, branches, Releases, original accepted data and original links. Set any GitHub archived flag only with separate user authority.

## Stop conditions and reporting

Stop before overwriting an active working checkout, pushing third-party/game material, changing a production payload, republishing an old version with new bytes, losing an unresolved branch, or claiming complete migration without ignored-data verification. Report repo/branch/head, imported tree and file-hash comparisons, isolated test status, exact outstanding local evidence, provenance/tag/release links and new commit SHAs for each independent mod. No runtime relaunch or gameplay acceptance is part of this migration.
