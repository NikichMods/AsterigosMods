# Work and verification

Stable main initially imports exact accepted Lua bytes. Future changes feature/* or research/*, tests then exact candidate commit/hash, installation only with closed game, explicit user runtime acceptance before main. VERSION is bundle version owner; increment for changed handed payload, never overwrite an old numbered artifact. Historical v1..v7 names remain historical local identities, not retrospective semantic releases. No public release is part of bootstrap.

Tests: Python3 + requirements-test.txt, run python tools/test.py. Source-path references were adapted for the new layout; runtime Lua files were not edited. Mock tests prove syntax, policies and API adaptation only, not real engine rendering. Local Lupa runtime is external and ignored. No new CI required to move already tested code; read CI_POLICY.md if adding it.

Installation: use local environment paths, inspect process state and installed identity; preserve current payload outside loader dirs, install only same-component files, verify hashes, record candidate and retain rollback. Never launch automatically: user's standing instruction is self-launch. Never hot-reload these widgets without cleanup. No installer is scaffolded at bootstrap.

ProfileRender and subtitle currently have accepted local payloads and historical build scripts/evidence under .local. Profile historical patch-targets.py defaults to1920×2160 and must NOT be used as a1600×1800 builder. A portable parameterized build recipe remains pending before changing/releasing those assets. No false claim of clean fully reproducible asset builds.

One active writer per checkout; new chat reads AGENTS.md, current docs, Git state and actual files. A chat is not the source of truth. GitHub private sync provides off-machine backup of tracked source/docs only; ignored local evidence/assets need their separate local archive.
