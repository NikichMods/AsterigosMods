# Продолжение по конкретному моду

Откройте общий локальный проект AsterigosMods. Для следующей задачи укажите в новом чате: «Работаем только над SoulsEnemyHUD. Прочитай корневой AGENTS.md, AGENTS.md этого мода и docs/STATUS.md внутри него. Следующая задача — интерфейс босса. Игру не запускай. Перед правками проверь, нет ли другого автора в том же checkout; для параллельной разработки используй отдельный worktree».

Другой мод получает отдельную задачу с его папкой. Одновременное редактирование разных папок одного checkout не считается изоляцией. Общий репозиторий публичный NikichMods/AsterigosMods; локальные пути и архивы — только в игнорируемом .local/environment.json. Исторический чат — архив, не источник актуальных требований.
