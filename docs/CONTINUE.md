# Продолжение работы

Откройте эту папку как локальный проект Codex и создайте рабочий чат в ней.

Первое сообщение может быть обычным: «Продолжим AsterigosMods. Прочитай AGENTS.md и текущее состояние. Следующая задача — интерфейс босса из docs/CURRENT_STATE.md. Сначала исследуй его устройство; игру не запускай». Перечитывать старый чат не требуется.

Текущий репозиторий — приватный NikichMods/AsterigosMods. Исходный чат остаётся архивом. Все пути к локальным данным записаны в .local/environment.json; этот каталог не отправляется на GitHub. Не открывать второй одновременно редактирующий чат в том же checkout.
